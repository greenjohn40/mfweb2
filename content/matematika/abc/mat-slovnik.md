# Matematika ve francouzštině – úvodní studijní materiál

### Slovník základních pojmů, obratů a symbolů pro výuku matematiky (Les mathématiques en français)

---

## 1. Úvod

Tento materiál slouží jako první opora pro žáky, kteří po třech letech výuky francouzštiny začínají studovat matematiku v tomto jazyce. Cílem není naučit se novou matematiku, ale **naučit se pojmenovat ve francouzštině to, co už znáte z hodin matematiky v češtině**. Materiál je rozdělen do tematických okruhů od nejobecnějších (pokyny učitele, práce se sešitem) až po pojmy z aritmetiky, algebry a geometrie.

Doporučujeme mít tento slovník po ruce při každé hodině a postupně si do něj doplňovat vlastní poznámky a příklady.

## 6. Rovnice a jejich úpravy (les équations et leurs transformations)

### 6.1 Základní stavební kameny rovnice

| Français | Čeština |
|---|---|
| une équation | rovnice |
| le premier membre / la partie gauche | levá strana rovnice |
| le second membre / la partie droite | pravá strana rovnice |
| un membre de l'équation | strana (člen) rovnice |
| le signe égal (=) | rovnítko |
| une variable / une inconnue | proměnná / neznámá |
| une expression | výraz |
| un terme | člen (rovnice, výrazu) |
| des termes semblables | podobné členy |
| une formule | vzorec |

**Poznámka:** Francouzština běžně používá pro „stranu rovnice" dvě různá slova – *la partie* (obecněji „část") i *le membre* (odborněji, typicky ve spojení *le premier membre*, *le second membre*). Obě varianty se v učebnicích objevují.

### 6.2 Úpravy rovnice

| Français | Čeština |
|---|---|
| transposer un terme | převést člen (na druhou stranu) |
| faire passer un terme de l'autre côté (en changeant son signe) | převést člen na druhou stranu (se změnou znaménka) |
| réduire les termes semblables | sloučit podobné členy |
| isoler l'inconnue | vyjádřit (izolovat) neznámou |
| exprimer une inconnue à partir d'une formule | vyjádřit neznámou ze vzorce |
| mettre en facteur / factoriser | vytknout (před závorku) |
| mettre un facteur commun en évidence | vytknout společný činitel před závorku |
| développer une expression | roznásobit výraz (odstranit závorky) |
| multiplier les deux membres par … | vynásobit obě strany rovnice … |
| diviser les deux membres par … | vydělit obě strany rovnice … |
| simplifier | zjednodušit |

*Příklad k vytýkání:* **2x + 2y = 2(x + y)** — *on met 2 en facteur* (vytkneme 2 před závorku).

### 6.3 Ekvivalentní a neekvivalentní úpravy

| Français | Čeština |
|---|---|
| une transformation équivalente | ekvivalentní úprava |
| une transformation non équivalente | neekvivalentní úprava |
| des équations équivalentes | ekvivalentní rovnice (se stejnou množinou řešení) |
| vérifier la solution (par substitution) | provést zkoušku (dosazením) |
| une racine étrangère (introduite par la transformation) | zdánlivý (cizí) kořen vzniklý úpravou |

Úprava je **équivalente**, pokud zachovává množinu řešení rovnice (např. přičtení stejného čísla k oběma stranám, násobení nenulovým číslem). Úprava je **non équivalente**, pokud může množinu řešení změnit (např. umocnění obou stran na druhou nebo dělení výrazem, který se může rovnat nule) — proto se po takové úpravě vždy doporučuje *vérifier* (zkouška dosazením).

### 6.4 Řešení – postup vs. výsledek

Francouzština stejně jako čeština rozlišuje mezi **řešením jako činností** a **řešením jako výsledkem**:

| Français | Čeština |
|---|---|
| résoudre une équation (sloveso) | řešit rovnici (postup) |
| la résolution (d'une équation) | řešení (jako postup, proces) |
| une solution / les solutions (podstatné jméno) | řešení (jako výsledek) |
| une racine (d'une équation) | kořen rovnice |
| l'ensemble des solutions | množina řešení |
| l'ensemble des racines de l'équation | množina kořenů rovnice |
| le domaine de définition (d'une équation) | definiční obor (rovnice) |
| l'équation n'a pas de solution | rovnice nemá řešení |
| l'équation a une infinité de solutions | rovnice má nekonečně mnoho řešení |
| l'équation admet une solution unique | rovnice má právě jedno řešení |

**Definiční obor rovnice** (*le domaine de définition*) je množina hodnot neznámé, pro které má rovnice smysl — typicky je třeba vyloučit hodnoty, při kterých by byl jmenovatel roven nule (*le dénominateur ne doit pas être égal à zéro*).

## 11. Praktická doporučení pro žáky

1. **Nepřekládejte v hlavě celé věty** – snažte se od začátku vnímat zadání jako celek (např. *„Résolvez l'équation"* rovnou jako pokyn k řešení rovnice, ne slovo po slově).
2. **Zapisujte si nová slovíčka do vlastního sešitu-slovníčku** rozděleného podle témat (algebra, geometrie…) – tento materiál doplňujte průběžně.
3. **Všímejte si rozdílů v zápisu čísel** (desetinná čárka místo tečky, mezery u tisíců).
4. **Čtěte nahlas** – správná výslovnost matematických výrazů (např. *„au carré", „racine carrée"*) se procvičí jen opakováním.
5. V případě nejasností použijte frázi *„Pouvez-vous répéter, s'il vous plaît ?"* nebo *„Qu'est-ce que ça veut dire ?"* – ptát se je naprosto v pořádku.
