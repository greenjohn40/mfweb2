Statistika 2 — Charakteristiky polohy

1. Aritmetický průměr

Aritmetický průměr $\bar x=\frac{1}{n}\sum_{i=1}^n x_i$ je součet hodnot dělený jejich počtem.

Příklad: teploty $18,21,19,23,20$ °C → $\bar x=\frac{101}{5}=20{,}2$ °C.

2. Vážený aritmetický průměr

$\bar x=\dfrac{\sum n_i x_i}{\sum n_i}$ — používá se, když hodnoty mají různou váhu (četnost, důležitost).

Příklad: známky $1,2,1,3$ vážené kredity $4,6,2,3$ → $\bar x=\frac{27}{15}=1{,}8$.

3. Vlastnosti aritmetického průměru

  • Přičtením konstanty $c$ ke všem hodnotám se průměr zvětší o $c$.
  • Vynásobením konstantou $k$ se průměr vynásobí $k$.
  • Součet odchylek od průměru je vždy $0$: $\sum(x_i-\bar x)=0$.

Příklad: data $10,14,8,12,16$ (průměr $12$) — po přičtení $5$ ke všem hodnotám je nový průměr $17$; po vynásobení $3$ je nový průměr $36$.

4. Geometrický průměr

$x_G=\sqrt[n]{x_1\cdot x_2\cdots x_n}$ — používá se pro průměrování tempa růstu (indexů, koeficientů).

Příklad: tržby firmy $800\to880\to950\to1100\to1250$ tis. Kč, meziroční indexy $1{,}100$; $1{,}080$; $1{,}158$; $1{,}136$ → průměrné tempo růstu $x_G\approx1{,}118$, tj. $11{,}8\%$ ročně.

Pro násobné (multiplikativní) veličiny je nutné použít geometrický, ne aritmetický průměr.

5. Harmonický průměr

$x_H=\dfrac{n}{\sum \frac{1}{x_i}}$ — používá se pro průměrování rychlostí/sazeb při stejné druhé veličině (např. stejná vzdálenost).

Příklad: cyklista jede tři stejně dlouhé úseky rychlostmi $15,20,12$ km/h → $x_H=\frac{3}{0{,}2}=15$ km/h.

6. Vážený harmonický průměr

Používá se při nákupu za stejnou částku (ne stejné množství) při různých cenách.

Příklad: nákup vždy za $300$ Kč při cenách $15,25,20$ Kč/kus → $47$ kusů za $900$ Kč, průměrná cena $\approx19{,}15$ Kč/kus.

7. Vztah mezi průměry

Pro kladná čísla, která nejsou všechna stejná, platí $x_H\leq x_G\leq x_A$ (rovnost jen při stejných hodnotách).

Příklad: $x_H=15\lt x_G\approx15{,}33\lt x_A\approx15{,}67$.

8. Modus

Modus $\mathrm{Mod}(x)$ je nejčetnější hodnota znaku. Pro intervalově tříděná data: $\mathrm{Mod}(x)=L+\dfrac{n_m-n_{-}}{(n_m-n_{-})+(n_m-n_{+})}\cdot h$.

Příklady: velikost boty u 20 lidí — modus $41$ (šestkrát). Doba čekání ve frontě, modální interval $\langle10;15)$ ($n_{-}=9$, $n_{+}=8$) → $\mathrm{Mod}(x)=10+\frac{15-9}{(15-9)+(15-8)}\cdot5\approx12{,}3$ min.

9. Medián

Prostřední hodnota seřazeného souboru; pro sudé $n$ průměr dvou prostředních hodnot.

Příklady: $7$ hodnot $68,74,75,79,82,88,91$ → medián $=79$. $8$ hodnot (totéž $+95$) → medián $=\frac{79+82}{2}=80{,}5$.

10. Kvantily, kvartily a box plot

Kvartily $Q_1,Q_2,Q_3$ dělí seřazený soubor na čtvrtiny ($Q_2$=medián). Mezikvartilové rozpětí $\mathrm{IQR}=Q_3-Q_1$ se používá pro box plot (krabice od $Q_1$ do $Q_3$, čára uvnitř = medián, vousy = min/max bez odlehlých hodnot).

Příklad: 20 hodnot → $Q_1=25$, medián $=39{,}5$, $Q_3=51{,}75$, $\mathrm{IQR}=26{,}75$.

Statistique 2 — Caractéristiques de position

1. Moyenne arithmétique

La moyenne arithmétique $\bar x=\frac{1}{n}\sum_{i=1}^n x_i$ est la somme des valeurs divisée par leur nombre.

Exemple : températures $18,21,19,23,20$ °C → $\bar x=\frac{101}{5}=20{,}2$ °C.

2. Moyenne arithmétique pondérée

$\bar x=\dfrac{\sum n_i x_i}{\sum n_i}$ — utilisée quand les valeurs ont un poids différent (effectif, importance).

Exemple : notes $1,2,1,3$ pondérées par les crédits $4,6,2,3$ → $\bar x=\frac{27}{15}=1{,}8$.

3. Propriétés de la moyenne arithmétique

  • Ajouter une constante $c$ à toutes les valeurs augmente la moyenne de $c$.
  • Multiplier par une constante $k$ multiplie la moyenne par $k$.
  • La somme des écarts à la moyenne vaut toujours $0$ : $\sum(x_i-\bar x)=0$.

Exemple : données $10,14,8,12,16$ (moyenne $12$) — après avoir ajouté $5$ à toutes les valeurs, la nouvelle moyenne est $17$ ; après multiplication par $3$, elle est $36$.

4. Moyenne géométrique

$x_G=\sqrt[n]{x_1\cdot x_2\cdots x_n}$ — utilisée pour moyenner un taux de croissance (indices, coefficients).

Exemple : chiffre d'affaires $800\to880\to950\to1100\to1250$ milliers Kč, indices annuels $1{,}100$ ; $1{,}080$ ; $1{,}158$ ; $1{,}136$ → taux de croissance moyen $x_G\approx1{,}118$, soit $11{,}8\%$ par an.

Pour les grandeurs multiplicatives, il faut utiliser la moyenne géométrique, pas la moyenne arithmétique.

5. Moyenne harmonique

$x_H=\dfrac{n}{\sum \frac{1}{x_i}}$ — utilisée pour moyenner des vitesses/taux à seconde grandeur constante (par ex. même distance).

Exemple : un cycliste parcourt trois tronçons égaux aux vitesses $15,20,12$ km/h → $x_H=\frac{3}{0{,}2}=15$ km/h.

6. Moyenne harmonique pondérée

Utilisée pour un achat à montant constant (et non quantité constante) à des prix différents.

Exemple : achat toujours de $300$ Kč aux prix $15,25,20$ Kč/pièce → $47$ pièces pour $900$ Kč, prix moyen $\approx19{,}15$ Kč/pièce.

7. Relation entre les moyennes

Pour des nombres positifs non tous égaux, $x_H\leq x_G\leq x_A$ (égalité seulement si toutes les valeurs sont égales).

Exemple : $x_H=15\lt x_G\approx15{,}33\lt x_A\approx15{,}67$.

8. Mode

Le mode $\mathrm{Mod}(x)$ est la valeur la plus fréquente. Pour des classes : $\mathrm{Mod}(x)=L+\dfrac{n_m-n_{-}}{(n_m-n_{-})+(n_m-n_{+})}\cdot h$.

Exemples : pointures chez 20 personnes — mode $41$ (six fois). Temps d'attente, classe modale $\langle10;15)$ ($n_{-}=9$, $n_{+}=8$) → $\mathrm{Mod}(x)=10+\frac{15-9}{(15-9)+(15-8)}\cdot5\approx12{,}3$ min.

9. Médiane

Valeur du milieu de la population triée ; pour $n$ pair, moyenne des deux valeurs du milieu.

Exemples : $7$ valeurs $68,74,75,79,82,88,91$ → médiane $=79$. $8$ valeurs (idem $+95$) → médiane $=\frac{79+82}{2}=80{,}5$.

10. Quantiles, quartiles et boîte à moustaches

Les quartiles $Q_1,Q_2,Q_3$ partagent la population triée en quarts ($Q_2$=médiane). L'écart interquartile $\mathrm{IQR}=Q_3-Q_1$ sert à la boîte à moustaches (boîte de $Q_1$ à $Q_3$, ligne intérieure = médiane, moustaches = min/max sans valeurs aberrantes).

Exemple : 20 valeurs → $Q_1=25$, médiane $=39{,}5$, $Q_3=51{,}75$, $\mathrm{IQR}=26{,}75$.
